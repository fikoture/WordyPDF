# Word to PDF

Mac uzerinde DOC veya DOCX dosyalarini PDF'e cevirmek icin basit yerel uygulama.

## Calistirma

1. `Word to PDF.app` dosyasina cift tiklayin.
2. `Dosya Sec` ile bir veya daha fazla `.doc` / `.docx` dosyasi secin.
3. PDF'lerin kaydedilecegi klasoru secin.
4. `PDF'e Cevir` dugmesine basin.

## Donusturme motoru

- Uygulama LibreOffice'in yerel PDF aktarma motorunu kullanir.
- En iyi gorunum icin dosyada kullanilan fontlarin Mac'te kurulu olmasi gerekir.

Ilk calistirmada macOS, uygulama icin dosya erisimi izni isteyebilir.

## Yeniden derleme

Kaynak kodu degistirirseniz:

```sh
./build.sh
```
